# Image inventory (procedural foliage plan, item 1)

Every image the game loads or ships: `assets/` (not the audio), and any `.png`, `.webp` or data URL in `js/`, `css/` and `index.html`. Base: main at 2709cbf.

**How the classes were decided.** The git history cannot say where an image came from: all 135 image files first appear in one commit (`14c5799`, 2026-10-06, the first commit of the repo as it is now), so there are no earlier commit messages to read. The evidence is what is in the repo: the comment at the top of `js/sprites.js` ("Retro Diffusion sprites, shrunk to true pixel size"), the tool scripts in `tools/` (`make_floor_decals.py`, `make_holo_ads.py`, `make_wall_holo_signs.py`) whose headers name the large source pictures they were cut from, the `originals/` folder (large pictures next to their game-size sprites), `docs/people.md` (Licensing) and the pictures themselves. **AI** = the repo itself says so. **AI (likely)** = no note says it, but the source is a large generated-looking picture in `assets/sprites/originals/`, or a sheet named by a tool script and not kept, or the look matches; the owner should say. **Licensed** = the Craftpix packs, kept. **Code-drawn** = no file.

Data URLs: none in `js/`, `css/` or `index.html` (the favicon is the empty `data:,`). CSS has no `url()`. Audio files are not images and are not listed (`docs/people.md` says their licensing is not documented; noted for the owner).
